# Alisa Project

**Alisa** — это развлекательный Discord-бот, который изначально был создан для моего личного сервера. Позже планировалось добавить функционал для масштабирования и приглашения бота на другие сервера, но, к сожалению, проект остался незавершенным.

> **Важно:** Этот проект находится в "сыром" состоянии. Код писался под старую версию библиотеки **Discord.js** и может требовать значительного обновления для работы с актуальными версиями API Discord.
